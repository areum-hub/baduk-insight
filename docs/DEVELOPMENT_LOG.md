# Baduk Insight — 개발 기록과 검증 현황

[README](../README.md) · [Windows 실행](SETUP_WINDOWS.md) · [시스템 구조](ARCHITECTURE.md)

**기준일: 2026-11-15 · Public GitHub `main`**

이 문서는 **현재 구현된 코드**, **과거 개발 결정**, **아직 실행 확인이 필요한 항목**을 구분합니다. GitHub에 반영된 것과 Windows PC에서 실행 검증한 것은 다릅니다.

## 1. 프로젝트 목표

프로 바둑 기보를 한 수씩 복기하면서 KataGo 추천 수를 필요한 때에만 확인하고, 작성된 바둑 개념 노트와 로컬 AI 질문을 활용해 공부하는 개인 학습 앱입니다. 정확하지 않은 승률·프로기사의 의도·실전 수읽기를 AI가 임의로 만들어내지 않도록 답변 범위를 제한합니다.

## 2. 구현 이력 (요약)

| 영역 | 현재 채택한 구현 | 남겨둔 이전 실험 |

## 3. 2026-11-15 UI 최종 결정

- **사이드바:** 기본 접힘. `01 · 오청원 기보 선택`, `02 · AI 착수 분석`, `03 · 학습 자료` 3개 카드
- **상단:** 바둑판과 재생 컨트롤 **65%**, KataGo 착수 분석 **35%**
- **정렬:** 대국명 및 대회·날짜·결과·파일명을 바둑판 위에 놓고 같은 왼쪽 시작점으로 맞춤. 바둑판·버튼·슬라이더는 최대 **720px** 레인
- **글꼴:** Noto Sans KR 우선. 영문·한글 공통 적용, 사용 불가 시 시스템 대체 글꼴. Streamlit Material Symbols 아이콘 글꼴은 일반 본문 글꼴로 덮지 않음
- **위계:** 메인 `Baduk Insight`는 축소한 헤더, 대국명은 작은 보조 제목, `AI 착수 분석`과 `바둑 개념 학습`은 구분되는 큰 섹션 제목
- **학습:** 상단 두 열 **아래 전체 너비**. 분야 선택 → 카드 하나 선택 → 원문 설명 표시
- **채팅:** 별도 'AI에게 추가 질문하기' 제목과 모델 설명 문구는 제거. 카드 설명 바로 아래 질문창과 대화 표시. 기본 AI는 **로컬 Qwen3 1.7B**
- **기보가 없는 상태:** 학습 카드 및 질문 영역은 계속 사용 가능

이 배치는 GitHub 코드에 반영했지만 실제 Windows 브라우저의 모든 화면 크기·아이콘·글꼴·스크롤은 아직 미검증입니다.

## 4. 코드 최신화 및 문서 정합성

2026-11-15에 저장소 트리 전체를 확인하고 README, Windows 가이드, 아키텍처, 개발 기록을 **현행 UI·데이터 흐름 기준**으로 새로 정리했습니다. 이전에 기록된 '채팅 없음', '질문 입력창 제거', '대국명 확대', 'UI에서 4B 모델 사용' 등의 상충 설명은 과거 변경 이력으로만 남기고 현재 기능으로 기술하지 않습니다.

소스의 기본 Ollama 채팅 모델 및 그 테스트의 기본값을 `qwen3:1.7b`로 일치시키고, 현재 사용하지 않는 Streamlit 구버전 RAG 상태 변수 및 사용되지 않는 표시 변수 등을 정리했습니다. CWI 선택 다운로드 스크립트에 남아 있던 현재 존재하지 않는 앱 버튼 설명도 수정했습니다.

**사용자 기능을 추가로 변경하지 않는 정합성 유지 작업**입니다. 기존 임베딩·ChromaDB 실험용 함수는 삭제하지 않았습니다.

## 6. Windows 최종 확인 순서

1. 공개 저장소 `main`의 원격 주소를 확인하고 `git pull --ff-only origin main` 실행
2. `.venv\Scripts\python.exe -m pytest -q`로 단위 테스트
3. Streamlit 재시작 후 **사이드바 아이콘이 문자로 보이지 않는지** 및 폰트 크기·바둑판 정렬 확인
4. SGF 불러오기 → 이전/재생·일시정지/다음·슬라이더를 이용해 2초 재생 확인
5. 학습 분야·카드 선택과 카드 바로 아래의 질문창 확인
6. `ollama pull qwen3:1.7b` / Ollama 실행 → 질문에 답변이 나오는지 확인
7. KataGo 로컬 경량 신경망 경로 설정 → 착수 직전 분석 및 마커 확인
8. CWI 공식 SGF 원격 로딩·실패 시 로컬 다운로드 대체 경로 확인

Windows 기기 또는 브라우저에서 실제 확인 전에는 검증 완료로 표시하지 않습니다.

## 7. 보안·제한

프로젝트는 **Public**이며 다운로드 SGF, KataGo 모델·실행 파일, `data/local/` 설정, `data/chroma/` 색인은 Git 관리 대상에서 제외합니다. 과거에 커밋된 파일은 `.gitignore`로 숨길 수 없으므로 공개 이력을 별도로 점검해야 합니다. 로컬 모델은 사용량당 외부 API 요금이 없지만 응답 품질 및 속도를 보장하지 않습니다. 특정 국면의 최선 수·승률·프로기사 의도는 생성형 설명으로 확정하지 않습니다.

원본 SGF와 외부 해설 저작권·사용 조건을 확인해야 합니다. 자세한 실행 절차는 [Windows 가이드](SETUP_WINDOWS.md)를 참고하세요.


## 8. 2026-11-15 재생·테스트·문서 정비

- 재생 중 위치마다 **수순 슬라이더의 위젯 키를 분리**해 자동 갱신과 세션 상태 직접 변경이 충돌하지 않도록 수정했습니다.
- 재생/일시정지 전환은 `toggle_playback`에서 처리하며, 다시 재생할 때 **2초 간격을 새로 시작**합니다. 위치별 슬라이더 키 회귀 테스트를 추가했습니다.
- 사용하지 않는 알파고 기보 3개 선택값을 제거한 상태에 맞춰 **CWI 직접 URL 테스트**로 변경했습니다.
- 더 이상 필요하지 않은 `start_baduk.ps1`, `scripts/download_cwi_samples.py`를 GitHub에서 삭제했습니다.
- Windows 실행 문서를 **GitHub ZIP 다운로드 방식**과 오청원 기본 기보 목록 중심으로 업데이트했습니다.
- **주의:** 이 변경만으로 Windows Streamlit의 실제 2초 자동 재생·일시정지·슬라이더가 검증 완료된 것은 아닙니다. 오류 메시지가 나타나면 정확한 예외와 실행 기보를 확인해야 합니다.
